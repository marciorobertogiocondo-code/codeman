# PEPITO — A Calopsita da Sorte

PWA baseada no protótipo oficial HTML v1.2.

## Publicação com GitHub Pages
1. No repositório, abra Settings → Pages.
2. Em Build and deployment, escolha Deploy from a branch.
3. Selecione a branch main e a pasta /(root).
4. Salve e aguarde a publicação.
5. Abra o endereço HTTPS do Pages no Chrome do Android.
6. No menu do Chrome, escolha Instalar app ou Adicionar à tela inicial.

## Arquivos
- index.html: aplicativo PEPITO v1.2.
- manifest.webmanifest: nome, ícones e configuração de instalação.
- sw.js: cache do aplicativo para uso offline após a primeira visita.
- icons/: ícones vetoriais do Pipito.

O primeiro acesso precisa de internet para carregar os arquivos e registrar o Service Worker.
